# 验收演示建议

这些内容只用于演示和验收，不写入正式行程配置，也不伪造成真实用户评论。

## 场景1：新旅程空态

- 打开四川之旅，显示2026-09-21至2026-09-28的8天行程。
- 时间轴显示9个主目的地：成都、黄龙、九寨沟、爱情海、三星堆、熊猫基地、都江堰、峨眉山、乐山。
- 没有Moment时显示空态文案。

## 场景2：D3九寨沟记录

- 选择D3九寨沟。
- 可展示可选细分点：则查洼沟、长海、五彩池、诺日朗瀑布、树正寨。
- 添加一条演示照片Moment，状态从“正在上传照片...”变为“发布成功”。

## 场景3：上传限制

- 上传61秒视频，提示“这段视频超过60秒，请裁剪后再上传”。
- 上传181秒语音，提示“这段语音超过180秒，请缩短后再上传”。
- 上传失败时，Moment保持草稿状态。

## 场景4：D4顺序调整说明

- D4展示爱情海、三星堆、成都。
- 三星堆细分点说明中保留“与黄龙或爱情海顺序可能按票务调整”的提示。

## 场景5：邀请与归档

- 邀请家人后复制邀请链接。
- 模拟登录过期，点击“恢复登录”回到四川之旅。
- 归档旅程后从默认首页隐藏，在“已归档”中仍可打开，并可恢复。
