# MOMENTS 四川之旅界面文案

## 基础按钮

- 开始记录
- 添加照片
- 添加视频
- 录一段语音
- 写一段文字
- 保存草稿
- 发布到旅程
- 继续编辑
- 重新上传
- 查看行程
- 邀请家人
- 复制邀请链接
- 恢复登录
- 归档旅程
- 取消归档

## Moment 编辑与上传状态

- 正在保存草稿...
- 草稿已保存
- 草稿保存失败，请稍后再试
- 正在上传照片...
- 正在上传视频...
- 正在上传语音...
- 正在发布...
- 发布成功
- 发布失败，内容已保留在草稿中
- 网络恢复后会继续上传
- 已暂停上传，点按可继续
- 这段视频超过60秒，请裁剪后再上传
- 这段语音超过180秒，请缩短后再上传

## 空态

- 还没有Moment。到达第一个地点后，可以用照片、视频、语音或文字留下这一刻。
- 这一天还没有记录。先看看行程，晚点再回来补上也可以。
- 这个地点还没有记录。到现场后再添加属于这里的Moment。
- 暂无已归档旅程。
- 暂无家人加入。邀请链接发出后，家人登录即可一起查看。

## 错误与限制

- 内容没有保存成功，请检查网络后重试。
- 上传失败，请重新上传。
- 文件格式暂不支持。
- 文件太大，请换一个文件再试。
- 当前登录已过期，请恢复登录后继续。
- 没有找到这段旅程，可能已被归档或链接已失效。
- 你暂时没有权限查看这段旅程。
- 行程加载失败，请稍后再试。

## 视频与语音规则

- 单段视频最长60秒。
- 单段语音最长180秒。
- 超过时长的内容不自动截断，需要用户确认裁剪或重新录制。
- 上传失败时保留本地草稿状态，避免用户重新输入。

## 邀请与恢复登录

- 邀请家人后，对方可通过链接加入这段旅程。
- 如果家人更换设备或登录过期，可使用“恢复登录”继续访问已加入的旅程。
- 恢复登录时优先展示最近一次加入的旅程；如果找不到记录，提示重新打开邀请链接。
- 邀请链接只用于加入旅程，不展示用户评论或虚构内容。

## 归档说明

- 归档后，旅程不再出现在默认首页列表中。
- 归档不会删除Moment、照片、视频、语音或行程配置。
- 已归档旅程仍可在“已归档”中查看和恢复。
- 恢复后，旅程回到默认首页列表。
